# Mental Health Web Application
## Built By: Sam Masciave, Hunter Boles, Luis Sanchez, Jace Howhannesian
------------------------

Project repository link: https://github.com/WPI-CS3733-2026C/team-37_4 <br>

<p>This web app was built in Windows Visual Studio Code, written in Python with a Flask framework, using SQLite3. Deployment to PythonAnywhere is pending.</p>

<p>Work on this project spanned half a semester in the Software Engineering course at WPI.
Our team of four drafted the concept for this web app as an independent project.</p>
<p>The app, currently called "Mental App", includes a number of features. Users can connect to others by creating mental health-related posts,
find useful resources for a number of mental health conditions, easily connect with available professionals, and more.</p>
<p>Throughout this project, I challenged myself to a wide variety of roles and tasks, gaining experience in front- and back-end development
and building on coordination, coding, and leadership skills alike. I greatly value this opportunity to create such a meaningful product with a wonderful team.</p>
